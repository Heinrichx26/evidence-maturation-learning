# Derived results

This directory stores aggregate outputs used for tables and figures.

## Included outputs

- `tables/`: compact CSV tables used for manuscript-level reporting.
- `experiments/`: experiment metrics, closure decisions, calibration summaries, frontier points, and run metadata.
- `data_quality/`: yearly NTSB evidence-completeness audit outputs and source hash summaries.
- `external_robustness/`: FAA AIDS and NASA ASRS source-audit summaries.

## Excluded outputs

Record-level sample tables with narrative text are excluded from this public repository. The included files are aggregate result tables, model-summary outputs, and reproducibility metadata.
